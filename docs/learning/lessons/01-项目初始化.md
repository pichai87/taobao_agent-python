# 第 1 课：项目初始化

## 1. 本阶段解决的问题

建立固定 Python 版本、可复现的 uv 环境和能运行的基础测试，为后续逐步实现 Agent 提供共同起点。本阶段没有模型调用或业务功能。

## 2. 在整体架构中的位置

这是 Intent Agent、Supervisor 和专家 Agent 的工程底座。原文技术栈采用 LangChain ReAct 与 LangGraph 多 Agent 编排；这些能力在需要时再加入，不因出现在架构图中就提前创建模块。

## 3. 修改的文件、类和关键方法

| 文件 | 作用 |
| --- | --- |
| `.python-version`、`pyproject.toml`、`uv.lock` | 固定 Python 3.13.16、项目元数据与当前解析结果 |
| `src/taobao_agent/__init__.py` | 最小可导入包；暂无业务函数 |
| `tests/test_project_setup.py` | `ProjectSetupTest` 检查运行版本及安装后的包导入 |
| `.gitignore`、`README.md` | 排除本地环境与密钥文件，说明运行入口 |
| `AGENTS.md`、`docs/learning/` | 保存长期规则、路线、本课与进度 |

## 4. 调用链、参数、State 和返回值

当前只有环境验证调用链：`uv sync` 读取 `.python-version`、`pyproject.toml` 与 `uv.lock`，创建 `.venv` 并安装 `taobao-agent`；`uv run python -m unittest discover -s tests -v` 进入项目解释器，发现并执行两个测试，最终以进程退出码返回结果。项目输入是配置文件与命令参数；输出是虚拟环境、安装后的包和测试报告。**当前没有 LangGraph State、节点或边。**

## 5. 关键代码的执行过程

`test_project_python_version` 读取运行中解释器的 `sys.version_info`，确认主次版本为 3.13。`test_package_can_be_imported` 先通过 `importlib` 导入 `taobao_agent`，再通过 `importlib.metadata` 查询已安装发行包的版本。两个断言同时通过，说明测试确实运行在配置的环境中，且包已安装并可导入。

## 6. 设计原因与替代方案

- **原文要求**：Python 后端、LangGraph 编排和 LangChain ReAct 是后续能力；文章未指定 uv 或 Python 小版本。
- **必要工程补充**：选择本机已安装且当前 LangGraph/LangChain 包元数据支持的 Python 3.13；用 uv 构建包并锁定环境。使用标准库 `unittest` 使首阶段无需下载测试框架。
- **替代方案**：平铺脚本不需要构建后端，但后续包导入与测试路径不够清晰；`pytest` 可在测试规模扩大时再引入。Python 版本若被后续必要依赖限制，再依据实际冲突讨论调整。

## 7. 实际测试结果与已知限制

在项目根目录实际执行 `UV_CACHE_DIR=/private/tmp/taobao-agent-uv-cache uv sync --offline`，退出码 0，创建 `.venv`，安装 `taobao-agent==0.1.0`。随后执行 `UV_CACHE_DIR=/private/tmp/taobao-agent-uv-cache uv run --offline python -m unittest discover -s tests -v`，2 个测试通过，退出码 0。缓存目录改到临时目录是因为默认 uv 缓存在当前沙箱中不可写。

最后使用 `uv sync --locked --offline` 检查锁文件，并用 `uv run --locked --offline python -m unittest discover -s tests -v` 复测：两条命令退出码均为 0，2 个测试再次通过。以上两条命令也使用同一个临时 `UV_CACHE_DIR`。

测试仅证明环境版本与包安装导入；没有验证 LLM、LangGraph 图、工具、SQL、外部数据或回答质量。

## 8. 本阶段涉及的上下文、通信与评估知识

第九章上下文工程和第十章通信协议尚未进入调用链。第十二章相关的起点是**区分验证层级**：本课的两个测试是环境/包级检查，不是 Agent 业务评测，更不是 LLM Judge 或外部基准。阶段 3 开始建立带预期意图和参数的电商样例。

## 9. Agent 岗位面试知识点

以下是常见工程知识点，不声称来自公开面经：为何固定解释器和依赖解析结果；为什么环境测试与 Agent 成功率是两类证据；如何让测试在没有模型密钥时仍可运行。模拟提问："项目本地可以导入，为什么不能据此宣称取数 Agent 可用？" 答案应说明导入只覆盖打包路径，业务正确性还需意图、工具、SQL、数据和答案证据的分层验证。

## 10. 下一阶段前置条件

用户确认进入阶段 2；确定可用的模型提供方及安全的凭据提供方式；掌握 LangGraph 的 State、节点、边和一次 `invoke` 的基本含义。下一阶段只实现一条用户输入到一次模型调用、结构化输出的最短路径。
